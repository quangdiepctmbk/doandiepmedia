# Machine Learning for Trading

## Tóm tắt

[[machine-learning-for-trading]] là repo GitHub của Stefan Jansen cho sách *Machine Learning for Trading, 3rd Edition*. Repo có hơn 19.5k sao, 5.3k forks và được cập nhật gần đây.

Dự án đi từ dữ liệu thị trường, feature engineering, mô hình ML, backtesting, quản trị rủi ro đến triển khai live trading.

## Điểm đáng chú ý

- Có 9 case studies trên ETF, crypto, NASDAQ-100, S&P 500, futures, FX, options.
- Nhấn mạnh tránh [[lookahead-bias]], data leakage, overfitting và multiple testing.
- Dùng walk-forward validation, Deflated Sharpe Ratio, White's Reality Check.
- Có hướng mới: GenAI, RAG, Graph RAG, multi-agent research systems.
- Có 6 thư viện ML4T: data, engineer, models, diagnostic, backtest, live.

## Giá trị cho phân tích chứng khoán

Dự án phù hợp để học quy trình phân tích chứng khoán bằng ML có kỷ luật: từ dữ liệu → tín hiệu → mô hình → kiểm chứng → quản trị rủi ro → triển khai.
