# ML4T Workflow

Research-to-production workflow: từ hạ tầng dữ liệu → feature → model → backtest → deploy → monitor.

## Các giai đoạn

1. **Data Infrastructure (Ch.2-5):** Dữ liệu point-in-time-correct, Volume/Dollar bars, synthetic data
2. **Research (Ch.6-13):** Feature engineering, labeling (triple-barrier), model development
3. **Strategy Design (Ch.14-17):** Chi phí giao dịch, quản trị rủi ro, xây dựng danh mục
4. **Evaluation (Ch.18-21):** Chứng minh lợi thế qua evidence boundary
5. **Production (Ch.22-27):** MLOps, drift detection, live trading
