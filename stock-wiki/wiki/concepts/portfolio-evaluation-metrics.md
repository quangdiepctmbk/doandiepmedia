# Portfolio Evaluation Metrics

Extends Chapter 16 backtest report with allocator-specific metrics.

## Metric Set (22+)

- **Return**: annualized return, volatility, Sharpe, Sortino, Calmar
- **Benchmark-Relative**: alpha, beta, information ratio, tracking error, active share
- **Diversification**: HHI (Herfindahl), effective N, risk contribution breakdown
- **Stability**: leverage stability, weight turnover, max position size
- **Drawdown**: max DD, avg DD, drawdown duration, ulcer index

NB01 demonstrates using ml4t-diagnostic (Plotly) as pyfolio replacement.
