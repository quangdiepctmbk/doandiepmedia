# TS Library Landscape: sktime

Unified forecasting with sktime — library that provides a consistent API across statistical (ARIMA, ETS), ML (reduced regression), and DL (LSTM, N-BEATS) forecasting methods.

NB11 demonstrates sktime's unified interface on ETF data, enabling systematic library comparison without manual wrapper code per model.
