# Quant Career & Learning Path

Chương 27 maps modern quant careers and learning systems.

## Five Quant Archetypes

- Quant researcher
- Quant trader
- Quant developer
- Portfolio manager
- Risk manager

The key industry trend is **quantamental**: systematic techniques blended with fundamental analysis.

## T-Shaped Expertise

Successful practitioners combine:

- Deep primary specialization
- Broad understanding across the trading lifecycle: data, research, portfolio construction, execution, risk, MLOps/governance

## Learning Arsenal

- Canonical texts: Chan, López de Prado, Ang, Harris, Hull
- Practitioner blogs, arXiv, aggregators
- Understand tool categories, not just individual libraries
- Open-source contributions, publishing, conferences as compounding career assets

## Failure Modes

- Over-specialization
- Underestimating soft skills
- Ignoring regulatory evolution
- Perpetual learning without application
